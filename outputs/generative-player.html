Rules

These are the numbers someone picked by ear — drag them while it plays.

Where the library ends and the composing begins

Every piece here splits cleanly in two. A theory library says which notes are allowed. Hand-written rules say when and how they sound. The first part is a lookup. The second part is the music.

const NOTES = toss(invert(chordNotes('Dbmaj9'), 1), [3,4,5]);  // library

NOTES.forEach(note => {
  const interval = rand(P.repeatMin, P.repeatMax);   // rule — now a slider
  const delay    = rand(0, P.maxDelay);              // rule — now a slider
});

No theory tells you the repeat should be 20–60 seconds rather than 5–10. Somebody chose it because it sounded right. Every number in the Rules panel above is one of those choices, and they're all yours to move.

Live vs. restart

Most sliders take effect on the next scheduled event, because the rules are read at event time rather than captured when the piece starts. A few are marked in amber — chord, octave range, voice count — because they change the piece's structure and need a quick rebuild. Samples are cached, so a rebuild is near-instant.

Things worth trying

  • Eno Machine → repeat 5–10s. Collapses Music for Airports into something restless and crowded. Then push it to 90–180s and it becomes barely-there.
  • Chimes → burst size 10+, spread 0.03. Turns gentle wind chimes into harp flourishes.
  • Drift → harmonise chance to max. Nearly every note blossoms into a chord; the piece stops being melodic and becomes hymn-like.
  • Circuit → density 0.2. The pulse nearly vanishes, leaving isolated ticks. At 2.0 it's a hocketing machine.
  • Tide → sweep speed to max. Slow ocean becomes an anxious pulsing.
  • Any piece → chord hold very short. Ambient becomes a chord progression, which is a good demonstration of why ambient holds chords so long.

How the rules were tuned

The default ranges and starting points for these sliders were hand-tuned: pick a number, listen for a while, change it, listen again. The panel above just makes that loop faster — every value you see started as a literal in the source before it became a slider. A few published generative.fm pieces share the same rule shape (loop period, phrase-reuse odds, gap scale) — those defaults are calibrated to match what works there.

A small note on naming. The samples are sampled every 4 semitones on the piano set and named csharp4.ogg, not Cs4 — accidentals land as words, not symbols. The library we use for chord and scale lookups (Tonal) is also sharps-only, so Db comes back as C#. It doesn't matter: the names go to a sampler, which cares about pitch, not spelling.
